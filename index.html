What this page does not do

  • It does not detect or bypass driving state. The checkbox is a human confirmation.
  • It does not upload results. It fetches one same-origin clip.
  • It does not request camera, microphone, location or vehicle permissions.
  • It does not test DRM, Netflix, or any access-controlled service.
  • It is a video-only player; audio synchronization is out of scope here.
  • It plays a local file in real time; it is not a network protocol or adaptive-bitrate test.
